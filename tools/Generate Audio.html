Generate audio clips

Makes one MP3 per letter and per concept-card word with Microsoft Azure neural voices, so the app has sound on every device, offline. Run it once per voice change; the app plays these clips first and falls back to the device voice for anything missing.

1 · Azure key (one-time)

  1. Sign in at portal.azure.com → Create a resource → search Speech → Create.
  2. Pricing tier Free F0 (0.5 million characters a month — all clips use under 5,000). Any region.
  3. Open the resource → Keys and Endpoint → copy Key 1 and the Location/Region (e.g. eastus).

The key stays in this browser only. Never paste it into the app, a commit, or a chat.

2 · Generate per language

Pick a voice, press Generate, and spot-check a few clips before downloading. On the free tier Burmese takes about 3 minutes.

LanguageVoiceClipsStatus

3 · Put the files in the app

  1. Unzip into your Scriptura_app folder, next to index.html. It creates audio/<language>/….
  2. Commit and push. The app picks the clips up automatically — no code change.
